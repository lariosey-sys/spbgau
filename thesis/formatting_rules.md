# Правила оформления LaTeX/PDF-версии ВКР

Этот файл фиксирует текущий рабочий стандарт оформления ВКР. За основу взят LaTeX-контур из соседнего репозитория `../vkr`, последняя проверенная сборка `thesis/build/87_ВКР_латех.pdf`. Материалы используются только как шаблон верстки; содержательные формулировки из старой ВКР в текущую работу не переносятся.

## Источник шаблона

- Эталонный пример: `thesis/reference_mifi_vkr/latex/87_ВКР_латех.pdf`.
- Эталонный LaTeX-исходник: `thesis/reference_mifi_vkr/latex/87_ВКР_латех.tex`.
- Рабочая преамбула текущей ВКР: `thesis/latex/preamble.tex`.
- Рабочий титульный лист текущей ВКР: `thesis/latex/title_page.tex`.
- Сборщик текущей ВКР: `thesis/scripts/build_thesis_latex.py`.

## Основные параметры страницы

- Класс документа: `extarticle`, A4, 14 pt.
- Основной шрифт: Times New Roman через `fontspec`.
- Язык: русский через `polyglossia`.
- Поля: левое 30 мм, правое 15 мм, верхнее 20 мм, нижнее 20 мм.
- Межстрочный интервал: полуторный.
- Абзацный отступ: 1.25 см.
- Интервал между абзацами: 0 pt.
- Переносы слов отключены, чтобы не получать разрывы вида `обозначе- / ния`.
- Нумерация страниц: стандартная нижняя нумерация `plain`.

## Структура документа

Целевой порядок служебных и основных разделов:

1. Титульный лист.
2. Реферат.
3. Содержание.
4. Перечень сокращений и обозначений.
5. Введение.
6. Основные главы.
7. Заключение.
8. Список использованных источников.
9. Приложения.

Текущая чистая сборка включает только разделы, которые уже можно показывать и вычитывать: реферат, содержание, перечень сокращений, введение, главу 1 и список источников. Главы 2-3, заключение и приложения временно исключены из сборки до нормального переписывания, чтобы в PDF не попадали технические черновики, IP-адреса, кодовые заготовки и таблицы низкого уровня.

Служебные разделы оформляются макросами:

- `\VkrStructuralSectionNoToc{...}` для реферата и содержания;
- `\VkrStructuralSection{...}` для введения, заключения, списка источников и перечня сокращений;
- `\VkrAppendixSection{<буква>}{<название>}` для приложений.

## Таблицы, рисунки и листинги

- Таблицы формируются через `longtable`, допускают перенос на следующую страницу.
- Широкие таблицы уменьшаются за счет меньшего `tabcolsep`, одинарного интервала внутри таблицы и `\small`.
- Рисунки ограничиваются макросами `\VkrFigure...`, чтобы не выходить за поля.
- Кодовые фрагменты оформляются через `listings` или `Verbatim` с рамкой и переносом длинных строк.

## Сборка

Основная команда:

```bash
cd thesis
bash export_latex_pdf.sh
```

Полная команда с вспомогательными DOCX/HTML-артефактами:

```bash
bash thesis/export_draft.sh
```

Сборщик создает версионированные артефакты в `thesis/diploma_builds/` с простой сквозной нумерацией:

- `ВКР-1.tex` и `ВКР-1.pdf`;
- `ВКР-2.tex` и `ВКР-2.pdf`;
- `ВКР-3.tex` и `ВКР-3.pdf`;
- далее по порядку.

Одновременно сборщик обновляет последние актуальные файлы:

- `thesis/assembled_draft_numbered.tex`;
- `thesis/assembled_draft_numbered.pdf`.

## Важные ограничения

1. Не переносить содержательный текст из reference МИФИ или соседнего `../vkr` в текущую ВКР.
2. Не править сгенерированные `assembled_draft_numbered.*` вручную; править исходные `.md`, `thesis/latex/*.tex` или сборщик.
3. После изменения текста или оформления запускать `bash thesis/export_draft.sh`.
4. Перед финальной сдачей титульный лист нужно сверить с актуальными требованиями кафедры СПбГАУ: название института, кафедры, код направления, руководитель и нормоконтроль могут отличаться от текущих рабочих заглушек.
