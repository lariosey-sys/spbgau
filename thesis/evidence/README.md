# Папка фактических доказательств

Сюда складываются материалы, полученные при запуске тепличной системы перед защитой.

Автоматический сбор:

```bash
bash thesis/collect_evidence.sh --start
```

Если контейнеры уже запущены:

```bash
bash thesis/collect_evidence.sh
```

Скрипт создает подпапку с timestamp и сохраняет состояние контейнеров, логи, MQTT-сэмпл, SQL-выводы и CSV-экспорты. Скриншоты dashboard нужно добавить вручную в созданную папку по именам, указанным в ее `README.md`.

Эти материалы используются для главы 3, приложений и замены evidence-slots в `thesis/defense_presentation.pptx`.
