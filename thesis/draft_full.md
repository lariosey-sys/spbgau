# Единый черновик ВКР

Тема: разработка и внедрение интеллектуальной системы управления микроклиматом в теплице на основе машинного обучения.

Этот файл служит сборочным оглавлением. Основной текст разнесен по отдельным файлам, чтобы главы можно было редактировать независимо и не дублировать большие блоки.

## Что нельзя забыть при финальной сборке

1. Заменить служебные citation keys на требуемый кафедрой формат ссылок.
2. Уточнить ГОСТ-описания источников, особенно preprint/online/CyberLeninka-источники.
3. Добавить скриншоты dashboard после запуска системы.
4. Добавить реальные примеры MQTT-сообщений из брокера.
5. Добавить пример выгрузки CSV/XLSX из `/api/export/sensors` и `/api/export/relays`.
6. Добавить рисунок схемы щитка в обычном формате изображения.
7. Экспортировать схемы из `thesis/diagrams.md` в формат PNG/SVG.
8. После накопления данных решить, включать ли фактические ML-метрики или оставить ML-раздел как подготовленный экспериментальный план.
9. Заменить в `thesis/defense_presentation.pptx` слоты доказательств на реальные скриншоты dashboard, MQTT-логи, SQL-строки и экспортированные схемы.
