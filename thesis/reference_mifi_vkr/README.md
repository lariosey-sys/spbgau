# Reference only: пример оформления готовой ВКР МИФИ

Эта папка содержит **только образец** из соседней ВКР МИФИ. Это не часть текущей работы по теплице, не источник содержания и не текст для заимствования. Материалы нужны, чтобы смотреть, как примерно выглядит готовый диплом: порядок служебных разделов, плотность текста, оглавление, оформление списка источников, приложений и шаблонов.

## Что скопировано

| Путь | Назначение |
|---|---|
| `final/Ларионов С.И_ВКР.pdf` | финальная версия ВКР из папки на отправку |
| `final/thesis_text.txt` | текстовая выгрузка финальной версии |
| `final/likeresult.txt` | дополнительная текстовая выгрузка/результат сравнения из исходного комплекта |
| `templates/` | шаблоны ВКР и задание на ВКР |
| `latex/87_ВКР_латех.pdf` | последняя проверенная LaTeX/PDF-сборка из соседнего репозитория `../vkr`, визуальный эталон верстки |
| `latex/87_ВКР_латех.tex` | LaTeX-исходник эталонной сборки для сверки правил верстки |
| `latex/title_page_mifi.tex` | исходный титульный лист МИФИ как пример структуры, не реквизитов текущей ВКР |

## Как использовать для текущей ВКР

1. Смотреть `final/Ларионов С.И_ВКР.pdf` как визуальный пример готового документа.
2. Смотреть `latex/87_ВКР_латех.pdf` как пример LaTeX/PDF-верстки: поля, шрифты, интервалы, служебные разделы, таблицы и листинги.
3. Смотреть `final/thesis_text.txt` как пример порядка разделов и плотности текста.
4. Использовать `templates/` только как ориентир по служебным страницам, если требования текущей кафедры совместимы.
5. Не переносить содержательные формулировки из МИФИ в текущую ВКР: тема, объект, методика и результаты здесь другие.

## Полезная структура из примера

В образце МИФИ итоговый документ устроен так:

1. Титульные страницы.
2. Реферат.
3. Содержание.
4. Термины и определения.
5. Перечень сокращений и обозначений.
6. Введение.
7. Глава 1: аналитический обзор.
8. Глава 2: центральный авторский методический/проектный результат.
9. Глава 3: экспериментальная часть и результаты.
10. Заключение.
11. Список использованных источников.
12. Приложение.

Для текущей ВКР по теплице берем этот порядок как ориентир, но наполняем его собственной логикой: расширяемая IoT/ML-платформа, управление микроклиматом, датчики, исполнительные устройства, журналирование, ML-прогноз и проверка эффективности выращивания.

- исходные главы старой ВКР;
- рабочие планы старой ВКР;
- рабочие артефакты и кеши.
